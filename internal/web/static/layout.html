pdf2word

A free, open source PDF to Word converter. Scanned pages are read with text recognition, in English and Odia.

  • No sign-up
  • No watermark
  • Open source
Source on GitHub

Convert

  • PDF to Word
  • PDF to DOCX
  • Scanned PDF to Word
  • Odia PDF to Word
  • PDF tables to Word
  • Several PDFs at once
  • Unselectable PDF text

Guides

  • Edit a PDF in Word
  • Resume or CV to Word
  • Contracts
  • PDF to Google Docs
  • Large PDFs
  • On a Mac

Built in Go. The PDF engine and the text recognition are inside the program, so it works without an internet connection.

Pages drawn by PDFium, scans read by Tesseract.
