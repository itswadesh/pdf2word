Every page, in the same place

Each line breaks where the PDF broke it and each page break falls where it fell, so a long document keeps its page count. A 384-page novel and a 136-page illustrated book converted to Word files with exactly 384 and 136 pages, each page starting with the same words.

Covers and full-page pictures get a section of their own with their own margins, so they fill the page in Word as they did in the PDF.

How long a big file takes

A PDF with text you can select converts in seconds, even at hundreds of pages. A scanned page takes a second or two to read, and several are read at once, so a 250-page scan takes a couple of minutes on a computer with several cores.

The converter shows the page it is on and the time left, and you can close the preview and keep reading this page while it works.

Over the limit?

Files are accepted up to 100 MB. Run the open source program on your own computer and you can set a higher limit.

Questions

Is there a limit on file size or number of files?

Up to 100 MB per file, and as many files as you like, one after another.

How long does a conversion take?

A PDF with selectable text takes seconds. A scanned page takes a second or two to read, and several pages are read at once, so a long scan takes a few minutes.

Will the Word document look like the PDF?

Close to it. Lines break in the same places and the page count matches. A typeface your computer does not have is swapped for Times New Roman, Arial or Courier New, and the spacing is adjusted so the lines still fit.
