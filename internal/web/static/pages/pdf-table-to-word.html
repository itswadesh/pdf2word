Real tables, not tabs and spaces

Many converters turn a table into lines of text pushed apart with spaces, which fall apart as soon as you edit a cell. Here a table drawn with lines becomes a Word table: rows, columns and cells, with each piece of text in the cell it sat in.

Comes across

  • Rows, columns and the text in each cell
  • Cells merged across columns
  • The colours of the ruling lines
  • Tables on scanned pages, where the PDF still has their lines

Not yet

  • Tables drawn without lines, which come across as plain text
  • Cells merged down a column
  • Tables on a plain scan, which has no ruling lines to read

Working with the table in Word

Click in any cell and type: the table grows as a Word table does. To add a row, press Tab in the last cell. To change the borders, use the Table Design tab.

If a table came across as text because it had no lines, select those lines in Word and use Insert, Table, Convert Text to Table, with tabs as the separator.

Questions about tables

Does it keep tables?

Tables drawn with lines become real Word tables you can type in, with the text in the right cells. Tables with no lines come across as plain text.

Will the Word document look like the PDF?

Close to it. Lines break in the same places and the page count matches. A typeface your computer does not have is swapped for Times New Roman, Arial or Courier New, and the spacing is adjusted so the lines still fit.

What file do I get?

A .docx file, the format Word has used since 2007. Google Docs, LibreOffice Writer and Apple Pages open it too.
