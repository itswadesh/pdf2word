Tips for a resume

A CV made from a Word file or Google Docs converts best, because its text can be copied out exactly. A scanned or photographed CV is read with OCR, which brings back the words but not bold and italic.

A typeface your computer does not have is replaced by Times New Roman, Arial or Courier New, with the spacing adjusted so each line still fits. If you have the original font, select all and set it again in Word.

Nothing is added to the file: no watermark and no link back, so the Word document is ready to send.
