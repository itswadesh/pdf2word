How converting several PDFs works

  1. 1
    Choose them all

    Select several PDFs in the file picker, or drop them on the page together. Files that are not PDFs are skipped with a note.

  2. 2
    Convert them in one go

    Pick the language of any scanned pages and press the button, which says how many files it will convert.

  3. 3
    Collect the Word files

    They are converted one after another and each DOCX downloads as soon as it is ready, named after its PDF. Your browser may ask once whether to allow several downloads.

Limits

There is no limit on the number of files and no daily limit. Each file can be up to 100 MB.

The list under the converter shows every file with its progress, any notes about it, and a button to download it again. Stop cancels a single file without touching the others.

Questions

Is there a limit on file size or number of files?

Up to 100 MB per file, and as many files as you like, one after another.

How long does a conversion take?

A PDF with selectable text takes seconds. A scanned page takes a second or two to read, and several pages are read at once, so a long scan takes a few minutes.
