Odia text recognition, built in

This converter was first written for Odia scans. When a page has no text to copy, it is read with Tesseract's Odia language data, and on this page Odia is already chosen for you. Pick English + Odia for pages that mix the two.

For the cleanest Odia text

  1. Scan at 300 dpi or more, so the small marks above and below the letters stay sharp.
  2. Choose Odia for Odia pages, and English + Odia where the two are mixed.
  3. A PDF that already has Odia text you can select is copied, not read, so it comes out exactly as stored.
  4. Dotted lines in a table of contents can come back as stray letters. Delete them in Word.

Odia, Hindi and other Indian scripts in Word

PDFs with Odia, Hindi, Bengali or Tamil text you can select keep it as text. The Word file asks for Nirmala UI, the Windows font that covers those scripts, so the letters do not turn into boxes; on a computer without it, another font with the script is used if there is one.

When the Odia comes out as strange letters

Many Odia documents, government notices among them, were typed in older fonts such as Akruti or Sreelipi. They draw Odia but store each letter as an English one, so the text copies out as a jumble like @û\ý aû¡Kýeò, and a Word file made from it shows the same jumble.

For those files, turn on Read every page as a scan before you press Convert to Word. The letters are then read from the page itself, the way a scan is. Choose Odia for pages in Odia only, and English + Odia where English words are mixed in. Plain type reads well; fancy headline fonts can still come back with mistakes, so check them. It takes longer, and bold and italic are lost, so leave it off for PDFs whose text copies out correctly.

Questions about Odia PDFs

Which languages can it read in scanned PDFs?

English, Odia and Hindi. English + Odia and English + Hindi handle pages that mix two of them.

Why are there strange characters in my Word file?

If the PDF was typed in an older Odia font such as Akruti, its text is stored as English letters: convert it again with Read every page as a scan turned on. Otherwise a scanned page was probably read in the wrong language, or the dotted leaders of a table of contents were read as letters. Pick the language the page is written in and convert it again, and delete any leftover dots in Word.

Can it convert a scanned PDF to Word?

Yes. Pages without selectable text are recognised automatically, including files where a print driver turned the text into outlines.

What file do I get?

A .docx file, the format Word has used since 2007. Google Docs, LibreOffice Writer and Apple Pages open it too.
