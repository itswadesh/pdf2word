    What comes across

    Fonts, sizes, bold and italic, headings, indents and alignment all survive the trip. Ruled tables become real Word tables you can type in. Pictures land where they were. Every line breaks where the PDF broke it and every page break falls where it fell, so the DOCX has the same pages as the PDF.

    Scanned PDFs and photos of paper

    A PDF that is only pictures has no text to copy out. Those pages go through text recognition, so you get words you can edit instead of a picture of words. English and Odia are built in, and the person running the converter can add more languages.

    Questions

    Is this PDF to DOCX converter really free?

    Yes. It is open source, there is no paid tier, and nothing is added to the file you get back.

    Will the Word document look like the PDF?

    Close to it. Lines break in the same places and the page count matches. A typeface your computer does not have is swapped for Times New Roman, Arial or Courier New, and the spacing is adjusted so the lines still fit.

    Can it convert a scanned PDF to Word?

    Yes. Pages without selectable text are recognised automatically, including files where a print driver turned the text into outlines.

    What file do I get?

    A .docx file, the format Word has used since 2007. Google Docs, LibreOffice Writer and Apple Pages open it too.

    Is there a limit on file size or number of files?

    100 MB per file by default, and as many files as you like, one after another. Whoever runs the converter can raise or lower the size limit.
