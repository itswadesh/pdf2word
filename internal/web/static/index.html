    PDF to DOCX without losing the layout

    The DOCX is laid out like the PDF, not poured into one long column. Every line breaks where the PDF broke it and every page break falls where it fell, so the Word document has the same pages as the PDF. A typeface your computer does not have is replaced by Times New Roman, Arial or Courier New, with the spacing adjusted so each line still fits.

    Stays as it was

    • Fonts, sizes, bold and italic
    • Headings, indents, alignment and tab stops
    • Tables drawn with lines, as real Word tables you can type in
    • Pictures, at their size and in their place
    • Page size, margins, line breaks and page breaks

    Not carried over yet

    • Text colours
    • Tables drawn without lines, which come across as plain text
    • Pages set in two or three columns, which are read across rather than down each column
    • Running headers and footers, which stay in the body of the page
    • Bold and italic on scanned pages

    Convert a scanned PDF to Word

    A scanned PDF is only pictures of pages, so there is no text to copy out. The converter spots pages like that and reads them with text recognition (OCR), so you get words you can edit instead of a picture of words. It also catches PDFs where a print driver turned the text into outlines. The reading is done by Tesseract, the open source OCR engine, and the result goes through the same layout step as any other page, so headings, alignment, indents and spacing are kept.

    For the cleanest text

    1. Scan at 300 dpi or more. A photo of a page works too, if the page is flat, sharp and evenly lit.
    2. Pick the language the page is written in. For pages that mix English and Odia, pick English + Odia.
    3. Pages that already have text you can select are copied, not read, so they come out exactly as written.
    4. A table of contents with dotted leaders can leave stray characters behind. Delete them in Word.
    5. Password-protected PDFs cannot be converted yet. Save a copy without the password first.

    Odia (ଓଡ଼ିଆ) PDF to Word, and other Indian scripts

    This converter was first written for Odia scans, and Odia text recognition is built in next to English. Choose Odia, or English + Odia for mixed pages, before you convert.

    PDFs with Odia, Hindi, Bengali or Tamil text you can select keep it as text, and the Word file asks for Nirmala UI, the Windows font that covers those scripts, so the letters do not turn into boxes. Whoever runs the converter can add more languages for scans.

    PDF or Word: which do you need?

    Keep the PDF for sending, printing and signing, when the page has to look the same everywhere. Convert it to Word when you need to change the words: update a CV, correct a contract, reuse the tables in a report or quote a scanned letter.

    Convert PDF to Word on any device

    In your browser

    The converter is a web page, so it works the same on Windows, macOS, Linux, Android and iPhone. On a phone, choose the PDF from your files and the Word document is saved to your downloads.

    On your own computer

    The whole converter is one open source program. On Windows it carries the PDF engine and the text recognition inside it, so it converts without an internet connection and the files never leave the computer.

    On your own server

    The source comes with a Docker setup, so an office or a school can run its own copy for everyone on its network. The source code is on GitHub.

    Questions about converting PDF to Word

    Is this PDF to DOCX converter really free?

    Yes. It is open source, there is no paid tier, and nothing is added to the file you get back.

    Will the Word document look like the PDF?

    Close to it. Lines break in the same places and the page count matches. A typeface your computer does not have is swapped for Times New Roman, Arial or Courier New, and the spacing is adjusted so the lines still fit.

    Can it convert a scanned PDF to Word?

    Yes. Pages without selectable text are recognised automatically, including files where a print driver turned the text into outlines.

    Which languages can it read in scanned PDFs?

    English and Odia are built in, and English + Odia handles pages that mix the two. Whoever runs the converter can add any of the more than 100 languages Tesseract has data for.

    Does it keep tables?

    Tables drawn with lines become real Word tables you can type in, with the text in the right cells. Tables with no lines come across as plain text.

    Can I convert a password-protected PDF?

    Not yet. Open it in a PDF reader that knows the password, save a copy without it, and convert that copy.

    Why are there strange characters in my Word file?

    Usually a scanned page was read in the wrong language, or the dotted leaders of a table of contents were read as letters. Pick the language the page is written in and convert it again, and delete any leftover dots in Word.

    Can I convert PDF to Word on my phone?

    Yes. Open this page in your phone’s browser, choose the PDF from your files, and the Word document is saved to your downloads.

    How long does a conversion take?

    A PDF with selectable text takes seconds. A scanned page takes a second or two to read, and several pages are read at once, so a long scan takes a few minutes.

    What file do I get?

    A .docx file, the format Word has used since 2007. Google Docs, LibreOffice Writer and Apple Pages open it too.

    Can it turn a Word file back into a PDF?

    No, it only goes from PDF to Word. Word, Google Docs and LibreOffice can all save a document as a PDF themselves.

    Is there a limit on file size or number of files?

    100 MB per file by default, and as many files as you like, one after another. Whoever runs the converter can raise or lower the size limit.
