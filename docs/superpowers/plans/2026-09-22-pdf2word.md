# pdf2word Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go CLI that converts PDF files (text or scanned) to `.docx`, using the text layer when present and Tesseract OCR otherwise.

**Architecture:** A linear pipeline — `pdftext` extracts glyphs and rebuilds paragraphs, `pdfimage` pulls embedded page images, `ocr` runs Tesseract over them, `docx` serialises the shared `model.Document`. `convert` decides per page whether to OCR; `cmd/pdf2word` only parses flags.

**Tech Stack:** Go 1.27 (no cgo), `github.com/ledongthuc/pdf`, `github.com/pdfcpu/pdfcpu v0.15.0`, `golang.org/x/image` (TIFF header decoding and fixtures), Tesseract 5 CLI at runtime.

**Spec:** `docs/superpowers/specs/2026-09-22-pdf2word-design.md`

## Global Constraints

- Go 1.27, `CGO_ENABLED=0` must build.
- Module path `pdf2word`; binary `pdf2word`.
- Only the standard library may be used by `internal/docx`.
- `go test ./...` must pass without Tesseract installed (OCR integration test skips).
- `gofmt` clean; `go vet ./...` clean.
- Commit after every task with a conventional-commit message.

### Task 7: convert orchestrator

**Files:** `internal/convert/convert.go`, `internal/convert/convert_test.go`

**Produces:**
```go
type OCRMode string   // OCRAuto="auto", OCROff="off", OCRForce="force"
type ImageSource interface { PageImages(path string, page int) ([]pdfimage.Image, error) }
type Options struct {
    OCR          OCRMode
    MinTextChars int              // default 20
    Engine       ocr.Engine       // nil → resolve Tesseract lazily via TesseractPath/Lang
    TesseractPath, Lang string
    Images       ImageSource      // nil → pdfimage default
    Logf         func(string, ...any)
}
type Report struct { Pages, OCRPages, EmptyPages int; Warnings []string }
func Convert(ctx context.Context, in, out string, opts Options) (Report, error)
func BuildDocument(ctx context.Context, in string, opts Options) (*model.Document, Report, error)
```
- Flow: `pdftext.Extract` → for each page decide `needOCR` per spec §6.1 → if needed and `Engine==nil`, resolve once via `ocr.Find`; on `ErrNotFound` return `fmt.Errorf("page %d needs OCR but %w; install Tesseract, pass -tesseract, or use -ocr off", ...)` → OCR each image, append `TextToBlocks`; page `Source=SourceOCR` if any text → write docx to `out+".tmp"` then `os.Rename`.

- [x] scanned.pdf, `off` → page empty, warning recorded, no error.
- [x] text.pdf, `force`, fake images present for page 1 → page 1 uses OCR text, page 2 text layer.
- [x] scanned.pdf, `auto`, `Engine==nil`, `TesseractPath="/nonexistent"` → error contains "needs OCR".
- [x] `Convert` writes a file; temp file absent afterwards; output unzips.
- [x] Integration `TestConvertScannedWithTesseract`: `ocr.Find("")` error → `t.Skip`; else expect page text to contain `"SCANNED"` and `"quick brown fox"` (case-insensitive).
